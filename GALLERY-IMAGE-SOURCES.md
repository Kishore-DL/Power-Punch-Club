# Gallery image sources

These photographs show other dojos and competitions, not Power Punch Club events. No club ownership or event history is claimed. All files were obtained from Wikimedia Commons on 23 November 2026.

The selected images are resized without cropping and converted to WebP. Derivatives retain the source license. Credit, source and license links are also stored with each editable gallery record and displayed on the full Gallery page.
